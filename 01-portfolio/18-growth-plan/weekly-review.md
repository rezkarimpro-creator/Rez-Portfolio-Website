# Weekly growth review

[README](README.md) · Draft · 29 Oct 2026 · Every Monday, 10 minutes. Rez reads the numbers; any session can fill the log from what he pastes.

## Where to look

| What | Where |
|---|---|
| Visits, top pages, top referrers | Cloudflare dashboard, rezkarim.com, Web Analytics (last 7 days) |
| Book clicks, bookings, messages, CV requests per source | https://rezkarim.com/stats (signed in) |
| Google clicks, impressions, top queries, pages not indexed | Search Console, rezkarim.com, Performance and Pages |
| Bing clicks (DuckDuckGo, Yahoo, Ecosia and ChatGPT search ride on it) and Copilot citations | Bing Webmaster Tools, Search Performance and AI Performance |
| Real visitors' speed (LCP, INP, CLS) | Cloudflare dashboard, Web Analytics, Core Web Vitals |
| New leads and replies | Gmail, mails to hello@rezkarim.com |
| First Monday of the month: AI answers | Re-run the questions in `marketing/geo-baseline.md` and add a dated column |

## Questions each week

1. Which channel brought the most calls or messages, and which brought visits but no leads?
2. Which page do leads land on first? Does it lead to Book a call within one click?
3. Any page Google won't index, or any query with impressions but no clicks (title or description to fix)?
4. One change for next week, picked from the answers above.
